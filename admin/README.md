# LawLink Super Admin Console (`/admin`)

The LawLink Super Admin Console is the central control platform for the **LawLink Legal Services Marketplace**. It provides platform administrators with RBAC-enforced controls for lawyer verifications, marketplace transactions, escrow releases, legal case tracking, NDPR compliance, AI matching weights, and system audit logging.

## Tech Stack
- **Framework:** React + TypeScript (Vite)
- **Styling:** Tailwind CSS + custom LawLink enterprise design system
- **State & Data Fetching:** TanStack Query + Axios API abstraction
- **Form Validation:** React Hook Form + Zod
- **Analytics Charts:** Recharts

## Getting Started
```bash
cd admin
npm install
npm run dev
```

App runs on `http://localhost:5174`.
