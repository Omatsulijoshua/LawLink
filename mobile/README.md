# LawLink AI — Mobile Application (`/mobile`)

Official **Flutter Cross-Platform Mobile Client** for iOS and Android.

## Features
- **4-Step AI Legal Intake Wizard:** Category, Location, Urgency, Fact Summary.
- **Verified Lawyer Directory:** Search, practice area filtering, and Supreme Court Call to Bar badges.
- **🚨 Emergency Network Portal:** Immediate on-call assistance for arrest, eviction, asset seizure.
- **Attorney-Client Privileged Workspace:** Encrypted Live Chat, Video Call, and Audio Call UI.
- **AI Legal Instrument Generator:** Ready-to-sign Tenancy Agreements, NDAs, Power of Attorney, Affidavits.
- **Encrypted Vault:** Secure storage for client title deeds and legal contracts.

## Getting Started
```bash
cd mobile
flutter pub get
flutter run
```
